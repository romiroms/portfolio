Export from QGIS
Right-click a layer → Export → Save Features As → GeoJSON. Use WGS 84 / EPSG:4326 for web mapping.

02

Add your layer
Use “Add GeoJSON” above. The file is read locally in your browser and is not uploaded to a server.

03

Publish permanently
Place your GeoJSON in the data folder and add it to the map configuration in js/main.js.
